# Platform PoC Glossary / ศัพท์เฉพาะในงาน Platform Operations

Scoped to this SOP. สำหรับศัพท์ครีเอเตอร์ทั่วไป (SKA, RS Tier, …) ดู
`creator-services-tiktok-shop` → `terminology/glossary.md`.

| คำ | ความหมาย |
|---|---|
| **Platform PoC** | Point of Contact ฝั่งแพลตฟอร์ม — ฟังก์ชันงานที่ประสานกับ TikTok Shop |
| **AM (Platform PoC)** | Account Manager ฝั่ง TikTok Shop ที่ดูแล MCN ของเรา — **คนเดียวกับ MCN Manager**. ผู้ติดต่อหลักสำหรับทุกเรื่องเกี่ยวกับแพลตฟอร์ม |
| **MCN Manager** | ดู AM (Platform PoC) — คนเดียวกัน |
| **CM (Creator Manager)** | ทีม Creator Manager **ของ TikTok Shop** ที่ดูแลครีเอเตอร์บางรายโดยตรง. ครีเอเตอร์ที่มี CM: ERISA ยื่น on-call ให้ไม่ได้ และไม่ถูกรวมใน Voucher Pool กลาง |
| **ERISA** | ERIDU's MCN arm — Creator Service department ที่เป็นเจ้าของ SOP นี้ |
| **MCN** | Multi-Channel Network — สังกัดครีเอเตอร์ |
| **On-call** | การยื่นเรื่องผ่าน AM ให้แพลตฟอร์มตรวจสอบ/whitelist เคสละเมิด |
| **Appeal / อุทธรณ์** | การยื่นโต้แย้งผลการละเมิด — ครีเอเตอร์ยื่นเองได้ หรือ AM ยื่น on-call ให้ |
| **False Detect** | ระบบ AI ของ TikTok Shop ตรวจจับผิด — เป็นเหตุผลหลักที่อุทธรณ์ผ่าน |
| **UID** | Unique Identifier ของบัญชีครีเอเตอร์ — **เปลี่ยนไม่ได้** แม้ handle เปลี่ยน |
| **Handle** | `@username` ของครีเอเตอร์ — **เปลี่ยนได้** |
| **Live Room ID** | ID ของห้องไลฟ์แต่ละ session — หาได้จาก MCN Partner Portal โดยใช้ timestamp |
| **GMV** | Gross Merchandise Value — ยอดขายรวม |
| **AOV** | Average Order Value = GMV ÷ จำนวนออเดอร์ |
| **Max Cap** | จำนวนเงินส่วนลดสูงสุดต่อคูปอง 1 ใบ — กำหนดโดยอิง AOV |
| **Min Spend** | ราคาซื้อขั้นต่ำที่ใช้คูปองได้ (ปกติเริ่มที่ 199.-) |
| **Quota** | จำนวนใบของคูปอง ≈ Budget ÷ Max Cap |
| **Voucher Pool** | งบคูปองกลางจาก Platform สำหรับครีเอเตอร์ในสังกัดช่วงแคมเปญ |
| **Redemption / % Used** | สัดส่วนคูปองที่ถูกใช้ไป — ERISA ดูได้เฉพาะ % ไม่เห็นรายชื่อผู้ใช้หรือ order รายใบ |
| **Coupon Display** | ช่องทางที่คูปองแสดง: Video / LIVE / Showcase |
| **Voucher Claim Period** | ระยะเวลาที่ใช้คูปองได้ |
| **Payday / Double Digit** | แคมเปญประจำเดือนของ TikTok Shop |
| **Brand Crazy Deal** | โปรแกรมลดราคาแบรนด์ดังของแพลตฟอร์ม — สินค้าที่เข้าร่วม **ใช้คูปอง MCN ไม่ได้** |
| **Flash Sales** | โปรลดราคาจำกัดเวลาของแพลตฟอร์ม — สินค้าที่เข้าร่วม **ใช้คูปอง MCN ไม่ได้** |
| **GO Live Challenge / Duration Challenge** | Mission รายไตรมาสฝั่งครีเอเตอร์ — วัดชั่วโมงไลฟ์สะสม |
| **MCN GMV Challenge** | Challenge ฝั่ง MCN ที่ผลตอบแทนเป็น **งบ Budget ให้ MCN จัดสรรคูปองเอง** |
| **Working Sheet** | ชีทกลางใน Lark ที่ใช้สื่อสาร/ส่งข้อมูลให้ Platform AM |
| **Lark** | เครื่องมือสื่อสารหลักระหว่าง MCN และ TikTok Shop |
