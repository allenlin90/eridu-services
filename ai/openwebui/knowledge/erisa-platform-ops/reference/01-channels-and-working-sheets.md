# ช่องทางและชีทอ้างอิง / Channels, Working Sheets and References

## เครื่องมือสื่อสารระหว่าง MCN และ TikTok Shop

เครื่องมือหลักคือ **Lark** และ **Working Sheet กลาง**.

**Onboarding ผู้รับผิดชอบใหม่:**

1. Set up บัญชี **Lark** — **ใช้ email ของบริษัทในการลงทะเบียน**
2. เข้ากลุ่มใน Lark
3. ขอ Access เข้า **Working Sheet กลาง**

## Working Sheets และชีทอ้างอิง

| ชีท / Reference | Link / Location |
|---|---|
| **ERIDU Working Sheet (Lark)** | Ask the AM (Platform PoC) or your team lead for the current link — internal URLs are deliberately not recorded in this repository |
| **Service Ticket** | `CS_Service Ticket` (แท็บที่ใช้: `Creator Issue Tracking`, `Creator Issue Tracking x TTS (Violation)`) |
| **Knowledge Base** | `CS_TikTok Shop: Knowledge Base` |
| **Creator CRM** | `EA_Creator CRM` (ใช้ค้นหา UID จาก Handle) |
| **TikTok Shop Partner Portal** | `https://partner.tiktokshop.com/compass/data-overview` (ใช้หา Live Room ID, GMV, จำนวนออเดอร์) |
| **การจัดลำดับยอดขาย + เกณฑ์ครีเอเตอร์ที่ได้รับการดูแลจาก CM** | `TikTok Shop Creator Tier by GMV` (latest update Mar, 2026) |
