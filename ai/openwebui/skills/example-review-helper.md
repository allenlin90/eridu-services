# Example Review Helper

Use when reviewing an example document.

This is a harmless verification skill created to test the Git-first Open WebUI
upload flow introduced in PR #353 (`ai/openwebui/claude-skills/upload-openwebui-skill`).
It is not intended for production use. Close this PR without merging once the
flow has been verified.

## Checklist

1. Confirm the document has a clear owner.
2. Confirm the document states its intended audience.
3. Flag any section that contradicts existing company policy.
